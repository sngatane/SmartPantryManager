# Smart Pantry Manager - Submission Checklist

## Application
- [ ] Pantry items can be added, edited, and deleted.
- [ ] Pantry data persists using SQLite.
- [ ] Recipes only match when all required ingredients and quantities are available.
- [ ] Recipe details and Settings screens are accessible.
- [ ] Empty states and input validation are implemented.

- [ ] Include the complete Android Studio project.
- [ ] Include the completed Word report with real screenshots.
- [ ] Include the narrated demonstration video in MP4 format.
- [ ] Include the public GitHub repository link in the report.
- [ ] Name the ZIP using the required student number and surname format.
