# Application Architecture

The application uses Java Android Activities to separate screens.

- MainActivity: pantry overview and navigation.
- AddEditActivity: ingredient entry and editing.
- RecipesActivity: suggested recipes.
- RecipeDetailActivity: recipe information.
- SettingsActivity: application information.
- PantryAdapter: pantry list presentation.
- PantryItem: pantry item model.
- DatabaseHelper: SQLite data operations.
