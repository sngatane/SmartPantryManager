# Functional Test Checklist

Use this checklist when verifying the application:

- [ ] Add a pantry item.
- [ ] Edit a pantry item.
- [ ] Delete a pantry item.
- [ ] Check suggestions with all required ingredients available.
- [ ] Check that a missing ingredient prevents a strict match.
- [ ] Open a recipe detail screen.
- [ ] Open Settings.
- [ ] Restart the application and verify persistence.
- [ ] Check the empty pantry state.
- [ ] Check the no-matching-recipes state.

Mark each item complete only after personally running that test.
